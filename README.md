## 5. Local Setup &amp; Deployment

### Run Locally
```bash
# Clone the repository
git clone https://github.com/mohamed267411-netizen/Portfolio.git
cd Portfolio

# Launch using Python's built-in HTTP server
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Deploy to GitHub Pages
1. Push your changes to the `main` branch:
   ```bash
   git add .
   git commit -m "refactor: update portfolio content and styles"
   git push origin main
   ```
2. Navigate to **Settings &rarr; Pages** in your GitHub repository.
3. Set **Source** to `Deploy from a branch`, choose `main` branch and `/ (root)` folder, then save.
