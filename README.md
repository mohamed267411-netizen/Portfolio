## 4. Accessibility &amp; Performance

- **Progressive Enhancement**: Content remains fully visible by default. Scroll reveal transitions are conditionally activated via `html.js-active`.
- **Reduced Motion**: Full support for `@media (prefers-reduced-motion: reduce)` which disables canvas rendering, circuit animations, and transitions.
- **High-DPI Canvas Rendering**: Dynamically scales particle coordinate space by `window.devicePixelRatio` for sharp rendering on 4K and Retina screens.
- **Resource Management**: Automatically pauses background animation loops when the tab is hidden (`visibilitychange` API).
- **Keyboard Navigation**: Focus rings with `2px solid var(--color-lime)` and `3px` offset, accessible skip-to-content anchor, and ARIA attributes on tablists.

## 5. Deployment Guide

### Deploying to Vercel (Recommended)
This repository includes a pre-configured `vercel.json` file for instant deployment:

1. **Via Vercel CLI**:
   ```bash
   cd d:\AI\por
   vercel
   ```
2. **Via Vercel Dashboard**:
   - Push your repository to GitHub.
   - Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
   - Select your repository.
   - Framework Preset: **Other** / **Static Site**.
   - Root Directory: `./` (leave default).
   - Click **Deploy**.

### Deploying to GitHub Pages
1. Push all project files to GitHub (`main` branch).
2. Go to **Settings &rarr; Pages**.
3. Under **Branch**, select `main` and root `/`.
4. Save and your site will be live at `https://mohamed267411-netizen.github.io/portfolio`.
